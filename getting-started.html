三步，把 AI 终端装进自己的机器 Three steps to your own AI terminal

准备一个 omts 服务端（自建，或先用官方免费版）→ 安装客户端 → 配对设备。全程可以让你的 AI agent 代劳。 Get an omts server (self-hosted, or the free tier) → install the client → pair your devices. Your AI agent can do most of it.

1服务端：自建，或先用免费版Server: self-host, or start free

Free · P2P only

官方免费 omtsOfficial free omts

零部署直接用：只支持设备与客户端之间的 P2P 直连，不含中继转发——网络条件差时无法回落。地址见发布说明，客户端内即可接入。Zero setup: devices and clients connect peer-to-peer only. No relay forwarding, so weak networks have no fallback. See the release notes for the address — connect right from the client.

Recommended

自建 omts（推荐）Self-host omts (recommended)

数据完全在自己手里，解锁中继回退（弱网也能连）、企业登录与多节点扩容。分单机和集群两种形态，见下。Your data stays yours. Unlocks the relay fallback for weak networks, enterprise sign-in, and multi-node scaling. Single-node or cluster, below.

01

单机部署Single node

一台 Linux 服务器：docker compose 拉起 omts + MySQL，nginx 做 TLS 反代公网入口。omts 只听 loopback，容器非 root、无 capability 运行。适合个人与小型团队。One Linux host: a docker compose file brings up omts + MySQL, with nginx in front as the TLS ingress. omts listens on loopback only; containers run non-root, no capabilities. For individuals and small teams.

02

集群部署（高可用）Cluster (high availability)

需要高可用时：云商 LB 挂多个 omts 实例，后端接高可用 MySQL（如 RDS）。节点无状态共享会话数据，滚动升级时在线任务不中断、客户端自动重连。For HA: put a cloud LB in front of several omts instances backed by a managed HA MySQL (e.g. RDS). Nodes are stateless and share session data — rolling upgrades keep live tasks attached while clients reconnect automatically.

your-agent@any-shell

在这台服务器上部署 omts（oh-my-term 服务端）：Deploy omts (the oh-my-term server) on this host:
1. 安装 MySQL 8，创建 omts 数据库Install MySQL 8 and create the omts database
2. 从 github.com/oh-my-term/releases 取最新 omts 发行版，核对 checksums.sha256Fetch the latest omts release from github.com/oh-my-term/releases and verify checksums.sha256
3. 以非 root systemd 服务运行，只监听 127.0.0.1Run it as a non-root systemd service, listening on 127.0.0.1 only
4. nginx 以 TLS 反代 443 到 omtsPut nginx in front with TLS on :443, proxying to omts
5. 验证 Verify https://<my-domain>/api/v1/version 返回 200returns 200

集群部署同理：把第 1 步换成托管高可用 MySQL，第 3 步在每台节点重复，入口换成云商 LB。详细 runbook 随发行版提供。The cluster path is the same recipe: managed HA MySQL in step 1, repeat step 3 per node, and swap the ingress for your cloud LB. The detailed runbook ships with each release.

3配对设备，打开会话Pair devices, open a session

1omtc 在你的机器上注册到服务端Register omtc on your machine with the server
2客户端核对 16 位 Bootstrap Commit（TOFU，防冒名）Verify the 16-character Bootstrap Commit in the client (TOFU anti-impersonation)
3创建会话——关掉客户端，手机接着用Start a session — close the client, pick it up on your phone

首次配对示例：First pairing looks like:

omtc@build-server
$ omtc register
